## 🔄 What Changed from v1.0 → v2.0

| Area | v1.0 | v2.0 | Reason |
|------|------|------|--------|
| **Personas** | 4 (Credibility Auditor + Fact Checker + Logical Analyst + Bias Detector) | 3 (Fact Checker + Logical Analyst + Bias Detector) | Credibility Auditor redundant — Team A already scores credibility |
| **Credibility scoring** | Team B (Credibility Auditor node) | Team A (R(d) formula output) | Single responsibility — Team A owns all evidence scoring |
| **LangGraph nodes** | 5 nodes (decompose → credibility → match_evidence → final_judgment) | 6 nodes (decompose → credibility → round1_qa → confidence_gate → round2_qa → final_judgment) | Agentic Q&A rounds added |
| **Reasoning style** | Single-pass parallel persona analysis | Adaptive 2-round memory-based Q&A loop | Matches AMPEND-LS MMAF design |
| **Semantic similarity** | BERT-Score proposed | cosine similarity via sentence-transformers | Already in stack — BERT-Score redundant |
| **Domain credibility** | Simple rule-based hardlist | Hybrid: Hardlist → MBFC cache → Dynamic fallback | Handles unknown Indian domains |
| **Evidence scoring formula** | Vague weighted sum | R(d) = 0.25·BM25 + 0.25·cosine + 0.25·domain + 0.25·recency | Explicit equal weights, matches AMPEND-LS Eq.4 |
| **Supervisor agent** | Not present | Merged into final_judgment node | Avoids extra complexity |
| **AAns agent** | Not present | Implicit — same DeepSeek call | One model handles both persona Q and A |
| **Confidence gate** | Not present | Added as conditional LangGraph edge at 0.80 | Routes to Round 2 only when needed |
| **Persuasion (PKM)** | Not mentioned | Documented as future work | Out of MVP scope |
| **GPU requirement** | Not addressed | Colab T4 + Ngrok (primary) / local GPU (if available) | Clarified deployment strategy |

## 🔄 Complete End-to-End Data Flow

**Scenario:** User sends Hindi text image to Telegram bot

```
STEP 0: User Input
  Telegram → "क्या व्हिस्की से COVID ठीक होता है?" (image)

STEP 1: Module 0 — OCR & Multilingual
  ├─ Tesseract (Hindi pack) → "क्या व्हिस्की से COVID ठीक होता है?"
  ├─ langdetect → {lang: "hi", confidence: 0.98}
  ├─ deep-translator → "Does whiskey cure COVID?"
  └─ Output: {normalized_claim: "Does whiskey cure COVID?", source_lang: "hindi"}

STEP 2: Module A — Evidence Retrieval
  ├─ Tavily: search "Does whiskey cure COVID?" → 30 results
  ├─ Top 2 through Trafilatura for full content
  ├─ 4-factor scoring on all results:
  │    who.int:     R(d)=0.94  [0.25·0.90 + 0.25·0.92 + 0.25·0.97 + 0.25·0.95]
  │    bbc.com:     R(d)=0.87
  │    twitter.com: R(d)=0.31  ← flagged as low-credibility
  ├─ Keep top-10 by R(d), discard rest
  └─ Output: evidence[] with combined_reliability scores

STEP 3: Module B — LangGraph Reasoning

  Node 1: decompose_claim
    Input: "Does whiskey cure COVID?"
    Output: ["Whiskey has antiviral properties",
             "Whiskey can kill SARS-CoV-2",
             "Drinking whiskey cures COVID-19"]

  Node 2: credibility_check
    Input: evidence[].combined_reliability
    avg_source_quality = mean([0.94, 0.87, 0.85, ...]) = 0.82
    flagged_sources = ["twitter.com" (R(d)=0.31)]

  Node 3: round1_qa  [6 DeepSeek calls]

    Fact Checker Q: "Does any retrieved evidence confirm
                     that whiskey has antiviral effects?"
    AAns A: "No. WHO and BBC both state alcohol does not cure
             COVID. No supporting medical evidence found."
    M₁ updated.

    Logical Analyst Q: "Is there a plausible biological
                        mechanism for whiskey to cure COVID?"
    AAns A: "No plausible mechanism. Ethanol concentration
             in whiskey is ~40% but blood concentration from
             drinking is far too low to kill viruses."
    M₂ updated.

    Bias Detector Q: "Is this claim associated with
                      manipulative health misinformation patterns?"
    AAns A: "Yes. Claim follows 'miracle cure' pattern common
             in COVID-era misinformation. Emotionally appeals
             to traditional medicine trust."
    M₃ updated.

  Node 4: confidence_gate
    stance_consensus  = 3/3 CONTRADICT = 1.0
    avg_source_quality = 0.82
    answer_certainty   = 1.0  (no uncertain phrases in M₃)

    confidence = 0.50×1.0 + 0.30×0.82 + 0.20×1.0
               = 0.50 + 0.246 + 0.20
               = 0.946

    0.946 >= 0.80 → ✅ SKIP Round 2 → go to final_judgment

  Node 6: final_judgment  [1 DeepSeek call]
    Supervisor check: factual ✅ logical ✅ bias ✅ → coverage 3/3
    S⁻ = 0.94+0.87+0.85+... (all contradict, high R(d))
    S⁺ = 0.0
    Verdict: FALSE
    Confidence: 97%
    Justification: "Claim contradicted by WHO and BBC (R(d)=0.94,0.87).
                    No biological mechanism (Logical Analyst, Round 1).
                    Matches miracle cure misinformation pattern."

STEP 4: Module C — Telegram Response
  ❌ FALSE — HIGH CONFIDENCE (97%)

  "Does whiskey cure COVID?" is FALSE.

  🔍 Evidence:
  • WHO: "Alcohol does not cure COVID-19"
  • BBC: "Medical experts refute alcohol cure claim"

  🧠 Analysis:
  • No antiviral biological mechanism
  • Matches known COVID misinformation patterns
  • Source trust: High (WHO, BBC, CDC)

  ⛔ Recommendation: Do not share this claim.
  Analysed in 1 round · TruthLens AI
```

## 🤖 LangGraph Node Configuration

```python
from langgraph.graph import StateGraph

# Node definitions
graph = StateGraph(VerificationState)

graph.add_node("decompose_claim",   decompose_claim_node)
graph.add_node("credibility_check", credibility_check_node)
graph.add_node("round1_qa",         round1_qa_node)
graph.add_node("confidence_gate",   confidence_gate_node)
graph.add_node("round2_qa",         round2_qa_node)
graph.add_node("final_judgment",    final_judgment_node)

# Fixed edges
graph.add_edge("decompose_claim",   "credibility_check")
graph.add_edge("credibility_check", "round1_qa")
graph.add_edge("round1_qa",         "confidence_gate")
graph.add_edge("round2_qa",         "final_judgment")

# Conditional edge — the key adaptive routing
graph.add_conditional_edges(
    "confidence_gate",
    lambda state: "round2_qa" if state["round1_confidence"] < 0.80
                               else "final_judgment",
    {
        "round2_qa":      "round2_qa",
        "final_judgment": "final_judgment"
    }
)

graph.set_entry_point("decompose_claim")
graph.set_finish_point("final_judgment")
```

## 📊 VerificationState Schema

```python
from typing import TypedDict, List, Dict, Optional

class VerificationState(TypedDict):
    # Set by Module 0
    claim:               str
    original_language:   str
    normalized_claim:    str

    # Set by Module A
    evidence:            List[Dict]   # includes combined_reliability per item
    sub_claims:          List[str]

    # Set by Node 1 (decompose_claim)
    claim_type:          str          # "factual" | "opinion" | "mixed"

    # Set by Node 2 (credibility_check)
    credibility_score:   float        # avg R(d) across evidence
    flagged_sources:     List[str]    # domains with R(d) < 0.30

    # Set by Node 3 (round1_qa)
    qa_memory:           List[Dict]   # [{round, persona, Q, A, insight}]

    # Set by Node 4 (confidence_gate)
    round1_confidence:   float
    rounds_executed:     int          # 1 or 2

    # Set by Node 6 (final_judgment)
    verdict:             str          # TRUE|FALSE|PARTIALLY_TRUE|UNVERIFIABLE
    final_confidence:    float
    justification:       str
    stance_breakdown:    Dict         # {SUPPORT: int, CONTRADICT: int, NEUTRAL: int}
    coverage_score:      float        # angles covered / total angles
    persona_insights:    Dict         # per-persona summary from memory
```

## 🎯 Design Decisions & Rationale

### Decision 1: Remove Credibility Auditor from Team B
**Chosen:** Team A computes R(d) credibility; Team B uses it directly  
**Rationale:** Single responsibility — no duplicate scoring  
**Removed:** Credibility Auditor persona from Team B  
**Impact:** 3 personas instead of 4, cleaner Team A→B contract

### Decision 2: Adaptive Q&A Rounds (not fixed)
**Chosen:** 1 round if confidence ≥ 0.80, 2 rounds if < 0.80  
**Rationale:** AMPEND-LS Fig. 2 shows diminishing returns after Round 2; adaptive saves LLM calls on clear cases  
**Alternative Rejected:** Fixed 2 rounds always (wasteful for obvious claims)

### Decision 3: Supervisor Merged into final_judgment
**Chosen:** Supervisor logic (coverage check) inside final_judgment node  
**Rationale:** Avoids adding a separate node for what is 5 lines of logic  
**Alternative Rejected:** Separate supervisor node (over-engineering)

### Decision 4: cosine similarity replaces BERT-Score
**Chosen:** sentence-transformers cosine similarity (already in stack)  
**Rationale:** Both measure semantic closeness — BERT-Score adds a library for the same output  
**Alternative Rejected:** BERT-Score via bert-score library (redundant dependency)

### Decision 5: Hybrid Domain Credibility
**Chosen:** Hardlist → MBFC cache → Dynamic (WHOIS + TLD + HTTPS)  
**Rationale:** MBFC has no API and doesn't cover Indian regional sites; dynamic fallback handles unknown domains  
**Advantage over AMPEND-LS:** AMPEND-LS uses static MBFC only; TruthLens handles unknown Indian sites dynamically

### Decision 6: Implicit AAns (not separate agent)
**Chosen:** Same DeepSeek call handles both persona question generation and AAns answering  
**Rationale:** One model, two roles via prompting — avoids multi-model complexity  
**Alternative Rejected:** Separate LLM instances per role (AMPEND-LS approach; impractical locally)

### Decision 7: Tesseract + deep-translator (not Helsinki-NLP)
**Chosen:** Tesseract OCR → deep-translator → DeepSeek multilingual fallback  
**Rationale:** Simpler stack, no additional model download, DeepSeek handles edge cases  
**Alternative Rejected:** Helsinki-NLP/opus-mt (separate translation model, more complexity)

### Decision 8: Local Ollama / Colab T4 (not cloud LLM API)
**Chosen:** Ollama local or Colab T4 + Ngrok  
**Rationale:** Zero per-query cost, privacy, no internet for reasoning  
**Advantage over AMPEND-LS:** AMPEND-LS uses GPT-4o mini (paid API); TruthLens is fully free

### Decision 9: Persuasion (PKM) as future work
**Chosen:** Not in MVP  
**Rationale:** PKM in AMPEND-LS only activates for UNCERTAIN cases; adds complexity without guaranteed gain in 6-week timeline  
**Future:** Add as post-submission enhancement

## 🚦 Current Gaps & Known Limitations

### Architecture Gaps
- [ ] Error handling: what if Ollama/Colab session drops mid-request?
- [ ] Fallback if Tavily API fails (Trafilatura-only path untested)
- [ ] Rate limiting for Telegram bot (multiple users simultaneously)
- [ ] Caching strategy for repeated claims (FAISS optional, not yet built)

### Integration Gaps
- [ ] Team A ↔ Team B JSON contract not yet end-to-end tested
- [ ] Team B ↔ Team C contract not yet tested
- [ ] Full pipeline not run on any LIAR claim yet

### Limitations vs AMPEND-LS
- No reverse image search (AMPEND-LS has this — future work)
- No knowledge graph entity extraction (AMPEND-LS has this — future work)
- No SLM distillation layer (AMPEND-LS uses DistilRoBERTa — future work)
- No persuasion detection (AMPEND-LS PKM — future work)
- Text-only (AMPEND-LS is multimodal — future work)

### TruthLens Advantages over AMPEND-LS
- ✅ Fully local deployment (zero cost per query)
- ✅ Indian language OCR (AMPEND-LS lists as future work)
- ✅ Working Telegram interface (AMPEND-LS is research-only)
- ✅ Dynamic domain credibility for unknown Indian sites
- ✅ Adaptive retrieval rounds (cost-efficient)
